# Whisper Local · Preview

Локальная диктовка для **Windows 10/11 x64** и **macOS 14+** — Apple Silicon и Intel.
Скачайте модель в приложении, выберите микрофон и диктуйте в обычные поля ввода.
Готовые сборки включают Python и движок распознавания. Аккаунт и API-ключ не нужны.

[English](README.en.md) · [Проверка перед выпуском](docs/VALIDATION.md)

## Первый запуск

1. Установите `WhisperLocal-Windows-Setup.exe`. На Mac откройте DMG своей архитектуры
   и перенесите **Whisper Local** в Applications.
2. В разделе **Модель** приложение предложит вариант по объёму памяти и доступной
   NVIDIA GPU. Можно выбрать другую модель: **Быстрая**, **Сбалансированная**, **Точная**.
3. Нажмите **Скачать и настроить**. Загрузка требует интернета; её можно отменить
   и продолжить. Файлы проверяются по закреплённым контрольным суммам.
4. Нажмите **Проверить диктовку**, выберите микрофон в «Основных» и произнесите фразу.
   Кнопка проверки позволяет начать и закончить запись без глобальной клавиши.

Готовая модель faster-whisper / CTranslate2 импортируется через **Выбрать папку…**.
На Mac можно выбрать движок **Metal / CPU · whisper.cpp**, скачать отдельную GGML-модель
или импортировать её файл `.bin`. OpenAI `.pt` и GGUF не поддерживаются.
После загрузки распознавание работает офлайн. Смена модели доступна в том же разделе;
настройка уже скачанной модели повторно проверяет её файлы.

## Диктовка

- **Windows по умолчанию:** удерживайте левый **Alt**, говорите, отпустите.
- **Mac по умолчанию:** удерживайте правый **Option**, говорите, отпустите.
- В **Основных** можно выбрать другое сочетание и режим **Удерживать** или
  **Нажать для начала / остановки**. Нажмите **Применить**; перезапуск не нужен.
  В режиме нажатия первое нажатие начинает запись, второе завершает её и запускает распознавание.
  Чтобы вернуть прежнюю клавишу, выберите **По умолчанию** и примените настройку.
- Esc, обычные сочетания редактирования и известные системные клавиши недоступны для назначения.
  Если ОС сообщает о занятом сочетании, прежняя настройка сохраняется. Горячие клавиши внутри
  других приложений требуют проверки в нужном поле. [Проверки клавиш и режимов](docs/DICTATION.md).
- **Esc** отменяет запись. Во время распознавания отмена завершает вычисление;
  модель автоматически загружается заново для следующей диктовки.
- При потере фокуса известного исходного поля во время записи диктовка отменяется,
  аудио отбрасывается. Если поле нельзя определить, остаётся ручное копирование результата.
- Приложение отправляет сочетание вставки в исходное поле, если цель не изменилась.
  Если автоматическая вставка не подходит, результат можно скопировать вручную.
- Enter не нажимается. Сообщения и команды приложение не отправляет.

Закрытие настроек оставляет программу в трее / строке меню. Для завершения выберите
«Выйти». Автозапуск включается пользователем в разделе «Система».
Максимальная запись — 3 минуты. Распознавание начинается после окончания записи.
После сна компьютера незавершённая диктовка отменяется. Дождитесь готовности модели
и начните новую запись. При отключении или остановке потока микрофона запись отбрасывается.
Если приложение не может надёжно определить исходное поле, текст остаётся для ручной вставки.

Обычная и мини-панель, зелёная/красная волна и наборы звуков Flow, Console, Air
сохранены. Происхождение звуков описано в [SOURCES.md](assets/sounds/SOURCES.md).

## Пользовательский словарь

В разделе **Словарь** добавьте правило **Whisper распознаёт → Как нужно писать**,
например `опен ай → OpenAI`. Выберите строку для редактирования или удаления.
Проверка на введённом тексте сразу показывает результат сохранённых правил.
Переключатель **Использовать замены при диктовке** отключает замены, сохраняя словарь.

Правила работают с целыми словами и фразами без учёта регистра; написание замены
сохраняется точно. Более длинная фраза имеет приоритет, повторных замен нет.
Словарь применяется после распознавания к тексту для вставки и копирования,
без перезагрузки модели. Правила сохраняются только в локальном `config.json`;
текст проверки не сохраняется. [Поведение и проверки](docs/DICTIONARY.md).

## Локальная очистка текста

В разделе **Очистка текста** включите очистку после распознавания и выберите
исправление пробелов или удаление междометий `эээ`, `эм`, `uh`, `um`.
Например, с обоими параметрами `эээ,  привет ,мир!` превращается в `привет, мир!`.
По умолчанию очистка выключена; параметры применяются сразу без перезапуска модели.

Предпросмотр показывает итог с учётом словаря. Правила словаря имеют приоритет,
написание замен сохраняется точно. Очистка сохраняет переносы строк, ссылки,
числа и текст в кавычках; слова «ну», «вот» и повторы остаются. Обработка работает
офлайн, текст проверки не сохраняется. [Правила, ограничения и проверки](docs/TEXT-CLEANUP.md).

## Вычисления и разрешения

**Windows:** автоматический выбор NVIDIA CUDA или CPU. Выпуск Windows включает
библиотеки CUDA/cuDNN; отдельно устанавливать Python, PyTorch или CUDA Toolkit не нужно.
Драйвер NVIDIA должен быть установлен. После ошибки загрузки или прогрева GPU приложение
пробует CPU и показывает фактический режим. «Процессор» принудительно отключает CUDA.

**macOS:** whisper.cpp использует Metal на поддерживаемом Apple или Intel Mac GPU.
Автоматический режим пробует Metal на Apple Silicon и выбирает CPU на Intel;
Metal на Intel можно включить явно, но он может быть медленнее CPU.
Доступность проверяется запуском настоящих вычислений; при неудаче модель работает на CPU,
а настройки показывают фактический backend. Для первого запуска подходят «Быстрая» и
«Сбалансированная». Существующие CTranslate2-модели остаются на CPU / INT8.
Скачивание нового формата начинается только по кнопке. [Проверки и ограничения](docs/MAC-METAL.md).

На Mac разрешите **Микрофон**, **Универсальный доступ** и, если macOS запросит,
**Мониторинг ввода**. В приложении есть кнопка запроса доступа к горячей клавише.
После выдачи доступа нажмите её снова или перезапустите приложение.
При запуске из исходников разрешения могут понадобиться терминалу / Python.

Preview-сборки пока не подписаны сертификатом издателя и не нотарифицированы Apple.
Для массового выпуска требуется настроить подпись и нотарификацию. Результаты CI
не заменяют проверку разрешений, микрофона и вставки на реальном Mac.

## Память

В разделе **Память** показаны RAM приложения и его процессов, а на Windows —
отдельная видеопамять GPU и общая память из RAM. Если счётчики GPU недоступны,
появится «Нет данных». На Mac расход Metal GPU отдельно пока не измеряется;
для CPU показано отсутствие отдельной VRAM.

Модель автоматически выгружается после **5 минут простоя**. Можно выбрать 1, 10,
30 минут или отключить выгрузку. Кнопка **Освободить память** завершает процесс
модели; файлы модели и последний текст сохраняются. Во время записи, распознавания
и вставки выгрузка недоступна. Следующая запись начинается сразу, параллельно с
загрузкой модели; если вы завершили запись раньше, результат дождётся её готовности.
Esc отменяет ожидающую запись. После выгрузки первый результат может задержаться.

Для faster-whisper режим **INT8 · меньше памяти** включается отдельно и перезагружает активную модель.
Фактический режим виден в «Системе». Автоматический выбор сохраняет CUDA/FP16
на NVIDIA и CPU/INT8, где он поддерживается. Замеры экономии, скорости и качества,
а также ограничения небольшого тестового корпуса описаны в [MEMORY.md](docs/MEMORY.md).

## Данные

- Windows: `%LOCALAPPDATA%\WhisperLocalOpen`.
- macOS: `~/Library/Application Support/WhisperLocalOpen`.
- `config.json` — настройки и добавленные пользователем правила словаря;
  `models/` — модели; `app.log` — технический журнал.
- Аудио проходит через память и локальные каналы процессов; записи диктовки на диск
  не создаются. Содержимое распознанного текста в журнал не записывается.
- Последний текст хранится в памяти до выхода. Для вставки временно используется
  буфер обмена; его прежнее содержимое восстанавливается, если пользователь ничего не скопировал.
- Сетевой доступ нужен отдельному процессу загрузки. В процессе распознавания включён
  offline-режим зависимостей и блокируются сетевые операции Python.

Новая Preview-установка использует отдельные данные, ярлык и запись автозапуска;
персональная установка в `Documents/WhisperLocal` не обновляется.

## Запуск из исходников

Для разработчиков нужен Python **3.12**. Установщик для пользователей его уже включает.

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
# Необязательно: библиотеки ускорения NVIDIA
.\.venv\Scripts\python.exe -m pip install -r requirements-gpu.txt
.\.venv\Scripts\python.exe app.py
```

`install.ps1` устанавливает исходники в `%LOCALAPPDATA%\Programs\WhisperLocalOpen-source`
и создаёт отдельные ярлыки **Whisper Local Preview**. `-CpuOnly` пропускает библиотеки NVIDIA.

macOS (запускайте Python той же архитектуры, что и будущая сборка):

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
# Для whisper.cpp / Metal нужны Xcode command line tools и CMake только при разработке:
.venv/bin/python scripts/build_whispercpp.py
.venv/bin/python app.py
```

## Проверки и сборки

```bash
python -m pip install -r requirements-build.txt
python -m unittest discover -s tests -v
python scripts/build_assets.py
python -m PyInstaller --noconfirm WhisperLocal.spec
```

Собирайте на целевой ОС. На Mac перед PyInstaller запустите `scripts/build_whispercpp.py`.
На Windows установите `requirements-gpu.txt`, если нужно
включить CUDA runtime. Inno Setup 6 собирает установщик из `packaging/windows.iss`.
На Mac получается `dist/Whisper Local.app` с отдельным helper-процессом внутри.

Workflow **Desktop builds** проверяет pull request на Windows, macOS ARM64 и macOS Intel,
собирает приложение и запускает распознавание тишины с настоящей моделью из сборки.
Установщик и DMG доступны в артефактах успешного запуска Actions; workflow сам не
публикует релиз и не сливает PR.

Сквозная проверка исходников без микрофона (скачивает около 141 МБ модели base):

```bash
python scripts/smoke_asr.py
```

Каждое улучшение разрабатывается в новой ветке `codex/…` и проходит через pull request.
Слияние выполняется только по отдельной команде владельца.

Проверки отмены, восстановления и полей ввода описаны в [RELIABILITY.md](docs/RELIABILITY.md).
