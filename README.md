# Whisper Local

Локальная диктовка в Windows с компактной плавающей панелью. Использует уже установленный на этом компьютере Faster Whisper **large-v3-turbo**, **CUDA / float16** и **RTX 5060 Ti**.

## Как пользоваться

1. Откройте **Whisper Local** с рабочего стола или из меню «Пуск».
2. Установите курсор в поле ввода — например, в редактор VS Code, браузер или Блокнот.
3. **Удерживайте левый Alt** и говорите. Панель появляется после короткого удержания, на ней движется волна микрофона.
4. **Отпустите Alt**. Whisper распознает речь и вставит результат в исходное поле. Короткий сигнал подтверждает успешную вставку.
5. **Esc** отменяет запись или ожидающий результат.

Сочетания Alt+Tab, Alt+F4 и другие сохраняются. Короткое нажатие Alt сохраняет обычное действие Windows. Правый Alt не занят.

Если во время распознавания изменилось окно или поле, программа оставит текст в панели. Верните курсор в нужное поле и нажмите «Вставить в поле» на панели; нажатие на белую карточку копирует текст. Программа не нажимает Enter и не отправляет сообщения, в том числе из терминала.

## Настройки

Нажмите чёрно-белый значок с волной в системном трее или откройте ярлык повторно. Повторный запуск открывает существующее приложение.

- Выбор микрофона. По умолчанию используется устройство Windows; при настройке это **ME6S**.
- Русский, английский или автоматическое определение языка.
- Раздел «Панель»: восстановлен прежний внешний вид — обычная 252×44 с 28 полосками и мини 184×48 с 18 полосками, тёмные круглые кнопки, зелёная Spotify или красная волна. Перетащить можно за любую часть капсулы, включая кнопки. Положение сохраняется; «Сбросить положение» возвращает её вниз по центру.
- Раздел «Звуки»: три набора — **Wispr Flow** из [официальной веб-демонстрации](https://wisprflow.ai/demo), **Console** с мягкими объёмными тонами в духе игровых консолей и тихий **Air**. Для каждого есть сигналы начала записи и успешной вставки. Есть громкость, выключатель и кнопки прослушивания. Все файлы находятся на ПК и играют без интернета. Console и Air — собственные звуки, не записи Sony.
- Автоматический запуск при входе в Windows.
- «Посмотреть панель» показывает внешний вид без включения микрофона.
- Поле «Попробуйте здесь» позволяет проверить настоящую диктовку.
- Меню значка в трее: приостановить диктовку, скопировать последний текст, выйти.

После успешной вставки показывается только небольшое подтверждение без карточки с текстом, чтобы не закрывать поле ввода. Закрытие окна настроек оставляет диктовку работающей в трее. Для полного завершения выберите «Выйти» в меню значка. Максимальная запись — 3 минуты.

## Что установлено

Рабочее приложение и отдельная среда интерфейса: `C:\Users\batae\Documents\WhisperLocal`.

Пользовательские настройки и технический журнал: `data/config.json` и `data/app.log` в папке приложения. Сигналы лежат в `assets/sounds`; версии с выбранной громкостью кэшируются в `data/cues`. Происхождение файлов указано в `assets/sounds/SOURCES.md`. Это звуки интерфейса, а не записи микрофона. Аудио и текст диктовки в журнал не записываются. Последний текст хранится только в памяти до выхода. Микрофон открыт только во время диктовки. Модель после запуска остаётся в видеопамяти для быстрого отклика; выход освобождает её.

Whisper и CUDA берутся из существующей установки:

Их файлы не изменялись. Если вы перемещаете исходную установку, обновите соответствующие пути в `data/config.json` и перезапустите Whisper Local. Приложение работает офлайн, загрузки моделей и подключения к сети при диктовке отключены.

## Совместимость

Работает с обычными редактируемыми полями, которые принимают Ctrl+V. Для окон, запущенных от администратора, Windows может блокировать автоматическую вставку из обычного приложения; используйте копирование результата. Защищённые поля и нестандартные игровые интерфейсы могут не поддерживать вставку. Качество текста определяется Whisper: отдельного редактора на базе языковой модели, как в Wispr Flow, здесь нет.

Буфер обмена временно используется для вставки и восстанавливается через 1,6 секунды, если за это время пользователь ничего другого не скопировал. Результат остаётся доступен через «Скопировать текст».

## Повторная установка из исходников

Запустите `install.ps1` в PowerShell. Нужен установленный Python 3.12. Скрипт устанавливает только зависимости интерфейса, создаёт ярлыки и включает автозапуск, если он указан в настройках. Существующие пути и настройки сохраняются. Модель не скачивается повторно.

Используются [Faster Whisper](https://github.com/SYSTRAN/faster-whisper), [Qt for Python](https://doc.qt.io/qtforpython-6/) и [python-sounddevice](https://python-sounddevice.readthedocs.io/).
