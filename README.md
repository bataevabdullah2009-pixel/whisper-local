# Whisper Local · Preview

Локальная диктовка для **Windows 10/11 x64** и **macOS 13+** — Apple Silicon и Intel.
Скачайте модель в приложении, выберите микрофон и диктуйте в обычные поля ввода.
Готовые сборки включают Python и движок распознавания. Аккаунт и API-ключ не нужны.

[English](README.en.md) · [Проверка перед выпуском](docs/VALIDATION.md)

## Первый запуск

1. Установите `WhisperLocal-Windows-Setup.exe`. На Mac откройте DMG своей архитектуры
   и перенесите **Whisper Local** в Applications.
2. В разделе **Модель** приложение предложит вариант по объёму памяти и доступной
   NVIDIA GPU. Можно выбрать другую модель: **Быстрая**, **Сбалансированная**, **Точная**.
3. Нажмите **Скачать и настроить**. Загрузка требует интернета; её можно отменить
   и продолжить. Файлы проверяются по закреплённым контрольным суммам.
4. Нажмите **Проверить диктовку**, выберите микрофон в «Основных» и произнесите фразу.
   Кнопка проверки позволяет начать и закончить запись без глобальной клавиши.

Готовая модель faster-whisper / CTranslate2 импортируется через **Выбрать папку…**.
Форматы OpenAI `.pt`, whisper.cpp и GGUF этим движком не читаются.
После загрузки распознавание работает офлайн. Смена модели доступна в том же разделе;
настройка уже скачанной модели повторно проверяет её файлы.

## Диктовка

- **Windows:** удерживайте левый **Alt**, говорите, отпустите.
- **Mac:** удерживайте правый **Option**, говорите, отпустите.
- **Esc** отменяет запись или ожидающий результат.
- Приложение отправляет сочетание вставки в исходное поле, если цель не изменилась.
  Если автоматическая вставка не подходит, результат можно скопировать вручную.
- Enter не нажимается. Сообщения и команды приложение не отправляет.

Закрытие настроек оставляет программу в трее / строке меню. Для завершения выберите
«Выйти». Автозапуск включается пользователем в разделе «Система».
Максимальная запись — 3 минуты. Распознавание начинается после окончания записи.

Обычная и мини-панель, зелёная/красная волна и наборы звуков Flow, Console, Air
сохранены. Происхождение звуков описано в [SOURCES.md](assets/sounds/SOURCES.md).

## Вычисления и разрешения

**Windows:** автоматический выбор NVIDIA CUDA или CPU. Выпуск Windows включает
библиотеки CUDA/cuDNN; отдельно устанавливать Python, PyTorch или CUDA Toolkit не нужно.
Драйвер NVIDIA должен быть установлен. После ошибки загрузки или прогрева GPU приложение
пробует CPU и показывает фактический режим. «Процессор» принудительно отключает CUDA.

**macOS:** в этом выпуске используется CPU / INT8 на Apple Silicon и Intel.
Apple GPU / Metal пока не используется. Модели «Быстрая» и «Сбалансированная» подходят
для начала; скорость зависит от компьютера и длины фразы.

На Mac разрешите **Микрофон**, **Универсальный доступ** и, если macOS запросит,
**Мониторинг ввода**. В приложении есть кнопка запроса доступа к горячей клавише.
После выдачи доступа нажмите её снова или перезапустите приложение.
При запуске из исходников разрешения могут понадобиться терминалу / Python.

Preview-сборки пока не подписаны сертификатом издателя и не нотарифицированы Apple.
Для массового выпуска требуется настроить подпись и нотарификацию. Результаты CI
не заменяют проверку разрешений, микрофона и вставки на реальном Mac.

## Данные

- Windows: `%LOCALAPPDATA%\WhisperLocalOpen`.
- macOS: `~/Library/Application Support/WhisperLocalOpen`.
- `config.json` — настройки; `models/` — модели; `app.log` — технический журнал.
- Аудио проходит через память и локальные каналы процессов; записи диктовки на диск
  не создаются. Содержимое распознанного текста в журнал не записывается.
- Последний текст хранится в памяти до выхода. Для вставки временно используется
  буфер обмена; его прежнее содержимое восстанавливается, если пользователь ничего не скопировал.
- Сетевой доступ нужен отдельному процессу загрузки. В процессе распознавания включён
  offline-режим зависимостей и блокируются сетевые операции Python.

Новая Preview-установка использует отдельные данные, ярлык и запись автозапуска;
персональная установка в `Documents/WhisperLocal` не обновляется.

## Запуск из исходников

Для разработчиков нужен Python **3.12**. Установщик для пользователей его уже включает.

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
# Необязательно: библиотеки ускорения NVIDIA
.\.venv\Scripts\python.exe -m pip install -r requirements-gpu.txt
.\.venv\Scripts\python.exe app.py
```

`install.ps1` устанавливает исходники в `%LOCALAPPDATA%\Programs\WhisperLocalOpen-source`
и создаёт отдельные ярлыки **Whisper Local Preview**. `-CpuOnly` пропускает библиотеки NVIDIA.

macOS (запускайте Python той же архитектуры, что и будущая сборка):

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

## Проверки и сборки

```bash
python -m pip install -r requirements-build.txt
python -m unittest discover -s tests -v
python scripts/build_assets.py
python -m PyInstaller --noconfirm WhisperLocal.spec
```

Собирайте на целевой ОС. На Windows установите `requirements-gpu.txt`, если нужно
включить CUDA runtime. Inno Setup 6 собирает установщик из `packaging/windows.iss`.
На Mac получается `dist/Whisper Local.app` с отдельным helper-процессом внутри.

Workflow **Desktop builds** проверяет pull request на Windows, macOS ARM64 и macOS Intel,
собирает приложение и запускает распознавание тишины с настоящей моделью из сборки.
Установщик и DMG доступны в артефактах успешного запуска Actions; workflow сам не
публикует релиз и не сливает PR.

Сквозная проверка исходников без микрофона (скачивает около 141 МБ модели base):

```bash
python scripts/smoke_asr.py
```

Каждое улучшение разрабатывается в новой ветке `codex/…` и проходит через pull request.
Слияние выполняется только по отдельной команде владельца.
