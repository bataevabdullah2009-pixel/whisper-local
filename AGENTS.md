# Development workflow

- Work on each coherent improvement in a new `codex/` branch and open a pull request.
- Do not merge a pull request without the user's explicit instruction.
- Use the checkout selected by the user for development. Do not install into,
  restart, or change settings of the personal installation in
  `C:\Users\batae\Documents\WhisperLocal` unless explicitly requested.
- Support Windows and macOS (Apple Silicon and Intel). Clearly distinguish code
  checks and CI builds from microphone, permissions, and paste tests on real Macs.
- Keep recording and transcription offline. Network access belongs only to an
  explicit model download. Never log microphone audio or transcription content.
- Preserve the compact recording capsule and existing sound choices.
